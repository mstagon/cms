# rest-forest 프로젝트 이미지

## 대문 이미지
이 폴더에 이미지 파일을 추가하세요. 파일명은 자유롭게 지정할 수 있습니다.

- `hero.*`로 시작하는 파일이 있으면 우선 사용됩니다
- 없으면 폴더 내 첫 번째 이미지 파일이 사용됩니다

예시: `hero.jpg`, `main-image.png`, `cover.webp` 등

## 아키텍처 이미지
`architecture/` 폴더에 이미지 파일을 추가하세요. 파일명은 자유롭게 지정할 수 있으며, 파일명 순서대로 자동으로 읽어옵니다.

예시: `diagram-1.jpg`, `system-arch.png`, `flow-chart.webp` 등
